## 1. 基本语法

```matlab
x = pi        % 等号=创建变量
y = sin(-5)   % 括号()用于函数输入
```

## 2. 桌面管理

- `save` 示例：`save data.mat` 将当前工作区保存到MAT文件中
- `load` 示例：`load data.mat` 将MAT文件中变量加载到当前工作区
- `clear` 清除工作区中的所有变量
- `clc` 清除命令行窗口的所有文本
- `format` 示例：`format long` 更改数值输出的显示方式

## 3. 数组类型

| 表达式 | 类型 |
| ------ | ---- |
| `4` | 标量 |
| `[3 5]` | 行向量 |
| `[1;3]` | 列向量 |
| `[3 4 5;6 7 8]` | 矩阵 |

## 4. 等间距向量

```matlab
1:4              % 使用冒号，创建一个从1到4，间距为1的向量
1:0.5:4          % 创建一个从1到4，间距为0.5的向量
linspace(1,10,5) % 创建一个从1到10，均匀间隔共5个元素的向量
```

## 5. 创建矩阵

```matlab
rand(2)    % 创建一个2行2列的方阵，方阵中的元素都是随机值
zeros(2,3) % 创建一个2行3列的矩阵，矩阵中的元素都为0
```

## 6. 索引

```matlab
A(end,2)   % 访问最后一行的第2列的元素
A(2,:)     % 访问第2行的所有列的元素
A(1:3,:)   % 访问前3行的所有列的元素
A(2) = 11  % 将数组A中的第2个元素修改成11
```

## 7. 数组运算

- 矩阵乘法 `*`：示例：`[1 3;2 4]*[3 0; 1 5] = [6 15;10 20]` 按照线性代数的矩阵乘法
- 按元素乘法 `.*`：示例：`[1 3;2 4].*[3 0; 1 5] = [3 0;2 20]` 按照元素对应相乘或广播扩展相乘

## 8. 多个输出

```matlab
[xrow,xcol] = size(x) % 将x中的行数和列数保存到两个变量中
[xMax,idx] = max(x)   % 计算x的最大值及其对应的索引值保存到两个变量中
```

## 9. 文档

```matlab
doc randi % 打开randi函数的文档页
```

## 10. 绘画

```matlab
plot(x,y,"ro-","LineWidth",5) % 绘制一条红色(r)虚线(--)并使用圆圈(o)标记，并设置线宽为5
hold on   % 将坐标区的保留状态设置为"打开"
hold off  % 将坐标区的保留状态设置为"关闭"
title("My Title") % 为绘图添加标签
xlabel("X") % 为x坐标系添加文字
ylabel("Y") % 为y坐标系添加文字
```

## 11. 使用表

```matlab
data.HeightYards  % 从表data中提取变量HeightYards
data.HeightMeters = data.HeightYards*0.9144 % 从现有数据中派生出一个表变量
```

## 12. 逻辑运算

```matlab
[5 10 15] > 12 % 将向量与值12进行比较
v1(v1 > 6)     % 提取v1中大于6的所有元素
x(x==999) = 1  % x中所有等于999的值替换成1
```

## 13. 编程

`if` 语句示例：

```matlab
if x > 0.5
    y = 3
else
    y = 4
end
```

`for` 语句示例：

```matlab
for c = 1:3
    disp(c)
end
```
