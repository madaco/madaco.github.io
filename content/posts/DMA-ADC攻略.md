# DMA+ADC攻略

## 1.好处

DMA+ADC搭配使用可以减少CPU的干预，ADC运行后直接将结果存放到内存中，无需再经过CPU搬运到数据寄存器的中间过程，并且有更快的传输速率与更低的延迟性。

| 模式            | 数据存放的过程                                       |
| --------------- | ---------------------------------------------------- |
| 非DMA的轮询模式 | ADC的数据寄存器->CPU读取->保存到用户变量(内存)中     |
| 非DMA的中断模式 | ADC转换完成触发中断->ISR读取数据寄存器->保存到内存中 |
| DMA模式         | ADC的数据寄存器->自动搬运到内存中                    |

## 2.配置ADC

为了提高程序的可移植性，设计程序时考虑兼容性的情况，尽量将代码接口封装，通过宏定义或函数输入适配不同的配置。本案例采用HC32F460芯片，首先先熟悉下该芯片的ADC外设。

该芯片有ADC外设分辨率是12位的，可配置成12位、10位、8位。

有两个ADC模块单元，ADC1和ADC2。

ADC外设需要2个时钟，模拟电路时钟ADCLK和数字接口时钟PCLK4。模拟电路时钟负责模拟电路的精准时序控制，用于驱动ADC核心的转换过程；数字接口时钟用于数字逻辑配置和数据的传输。PCLK4与ADCLK时钟频率比可选择：1:1、2:1、4:1、8:1、1:2、1:4。

采样率2.5MSPS。

最多17个模拟输入通道，其中16个外部通道，1个内部通道。

AD转换触发的条件可选：软件触发(仅ADC待机时使用、仅适用于序列A)、外设触发、外部引脚触发。

ADC有2个扫描序列A和B，可任意指定单个或多个通道，AD转换的模式可选：序列A单次扫描、序列A连续扫描、双序列扫描(A、B触发源独立，序列B优先于序列A)，同步模式。

会触发的中断或事件：序列A扫描结束、序列B扫描结束、模拟看门狗通道比较中断、序列比较中断。

AD转换数据平均值计算功能：对同一通道连续转换2/4/8/16/32/64/128/256次，再将平均值保存到数据寄存器中。

ADC1支持可编程增益放大器PGA，可以对模拟输入进行指定倍数放大，再进行AD转换，增益倍数范围：x2~x32。

多ADC协同工作模式，ADC2和ADC3跟随ADC1同步触发，这个模式软件触发无效，禁止序列B动作。

| 四种协作工作模式 | 原理                                                         |
| ---------------- | ------------------------------------------------------------ |
| 单次并行触发模式 | 协同触发，只触发一次                                         |
| 单次延迟触发模式 | ADC1触发后，经过指定延迟时间触发ADC2，再经过指定延迟触发ADC3，只触发一次 |
| 循环并行触发模式 | 协同触发，经过指定延迟时间再次协同触发，直到主动停止ADC1或禁止协同模式 |
| 循环延迟触发模式 | ADC1触发后，经过指定延迟时间以此触发ADC2、ADC3、ADC1，循环延迟触发 |

## 3.配置DMA

该芯片有2个DMA控制单元，每个DMA有4个通道，共8个独立通道，每个通道触发源独立。4通道优先级：通道0>通道1>通道2>通道3，同时有多通道传输按照优先级顺序执行，当低优先级在传输时不会被打断，传输完成后再传输高优先级通道数据。

每次请求传输一个数据块，一个数据块可设置为1-1024个数据，数据宽度可设置为8bit、16bit、32bit，可配置最多65535次传输(0xFF)。

源地址和目的地址可独立配置为：固定、自增、自减、循环或指定偏移量的跳转。

会触发的中断：数据块传输完成中断、传输完成中断、传输错误中断。

支持连锁传输功能，可实现一次传输多个数据块。

## 4.ADC+DMA

在DMA配置中源地址选择ADC的数据寄存器，目的地址选择存储AD值的全局变量，DMA触发源设置为ADC的序列A扫描完成。这样ADC扫描完成后，DMA就会自动搬运转换后的AD值。
