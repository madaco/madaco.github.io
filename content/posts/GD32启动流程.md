# GD32 启动流程

GD32 的 startup.s 程序分析。整个汇编程序分为以下几个段：stack 栈区段、heap 堆区段、vector 异常向量表、|.text| 代码段。

## 1. stack 段

定义栈区大小、栈底地址和栈顶 sp 指针。

## 2. heap 段

定义堆区大小、堆区地址和结束地址。

栈区堆区内存示意图：

```
----高地址----栈顶
1KB ?(增长方向)
----低地址----栈底

----高地址----堆区结束地址
1KB ?(增长方向)
----低地址----堆区开始地址
```

## 3. vector 段

定义各个异常服务程序。

### reset 处理程序

1. systeminit 函数：初始化时钟配置、Flash 设置
2. __main 函数：运行 scatterloader 函数，将 RO 和 RW 段从装载域复制到运行域，ZI 段运行域的初始化；运行 rt_entry 函数，初始化堆区和栈区数据，跳转到用户的 main 函数中

其他大部分异常服务函数是死循环。

### 利用外部中断实现某些功能步骤

1. 通过 NVIC 设置分组
2. 使能对应的中断类型，设置抢占优先级和子优先级
3. 设置中断源
4. 设置中断类型（中断模式还是事件模式）、触发类型
5. 清除中断标志位
6. 定义中断服务函数

## 内存分布

- RAM：全局区、栈区、堆区
- ROM：常量区、代码区
