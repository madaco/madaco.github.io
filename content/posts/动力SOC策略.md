# 动力SOC策略（磷酸铁锂）

## 1.

当前程序中有显示SOC和真实SOC，实际计算的是真实SOC，显示SOC是为了避免SOC突然带来的负面影响，以一定的速度向真实SOC逼近。

### 1.1 满充校准策略

真实SOC校准：电池在充电过程中，当电流小于0.2C，并且最高单体电压大于查表法校准SOC（或满充电压-50mV），满足条件维持3s，校准真实SOC至100%。

| 温度/℃ | -20  | 0    | 10   | 20   | 50   |
| ------ | ---- | ---- | ---- | ---- | ---- |
| 电压/V | 3.55 | 3.55 | 3.5  | 3.5  | 3.5  |

显示SOC校准：最高电压大于3.65V（0℃~60℃），把显示SOC校准到100%。

### 1.2 电流积分

实时采集的电流数据与单位时间的乘积即积分电量Qadd。

随着电池放电或充电，可放电容量CurQ会进行衰减或增加，CurQ=CurQ-Qadd。（Qadd可正可负，正数代表放电，负数代表充电）

积分更新颗粒度的选择：当积分容量Qadd达到Min（0.001*额定容量，0.5Ah）时，才会将该积分电量更新到可放电容量CurQ中。

积分溢出边界控制：控制可放电容量CurQ大小，避免达到0或超出最大可用容量。

### 1.3 温度修正策略

在低温情况下电芯中的部分电量被冻结没法使用，因此引入温度~容量保持率的表格，方便计算低温下的可用容量。

冻结容量=（1-容量保持率）* 设计容量 * SOH

真实SOC=（剩余容量-冻结容量）/（总容量-冻结容量）=剩余可放容量/（设计容量 * SOH-冻结容量）

### 1.4 平滑处理

显示SOC会按照一定的速率追随真实SOC。

追随开始的前提：

a.放电时，真实SOC下降0.3%后开始修正，之后真实SOC每变化0.1%，显示SOC以相应的速率变化。

b.充电时，真实SOC上升1%后，显示SOC开启修正。

dt显示SOC=dt真实SOC * 修正速率

修正速度=（显示SOC-重合点）/（真实SOC-重合点）

a.放电时，分为6个区间

|         |          |        |         |         |         |        |
| ------- | -------- | ------ | ------- | ------- | ------- | ------ |
| SOC区间 | 100%~70% | 70~50% | 50%~30% | 30%~15% | 15%~10% | 10%~0% |
| 重合点  | 40%      | 25%    | 15%     | 8%      | 5%      | 0%     |

b.充电时，分为6个区间

|         |        |         |         |         |         |          |
| ------- | ------ | ------- | ------- | ------- | ------- | -------- |
| SOC区间 | 0%~10% | 10%~50% | 50%~65% | 65%~75% | 75%~85% | 85%~100% |
| 重合点  | 15%    | 75%     | 80%     | 88%     | 95%     | 100%     |
