matlab 脚本常用函数，全部可以通过 matlab 文档查询。

```matlab
% 清空命令窗口（清除屏幕显示）
clc;  
% 清除当前工作区所有变量（释放内存空间）
clear;

% 基本循环结构语法（此处为示例，实际代码中未使用）
% for index = values
%     statement
% end

% 获取数组长度函数
length();

% 获取Simulink模型参数函数
value = get_param(object,parameter);

% 向指定工作空间写入变量函数
assignin(ws,var,val)

% 清空命令窗口并重置环境
clc;
% 清除所有变量、关闭所有文件、重置工作空间（更彻底的清理）
clear all;

% 创建参数扫描序列：1到10的奇数数组 [1,3,5,7,9]
ns = 1:2:10;
% 初始化结果存储数组
result = [];

% 开始参数扫描循环
for i = 1:length(ns)
    % 获取当前迭代的n值
    n = ns(i);

    % 指定要操作的Simulink模型名称
    mdlName = 'untitled1';

    % 获取模型的工作空间对象
    mdlWks = get_param(mdlName, 'ModelWorkspace');

    % 将当前n值写入模型工作空间
    % 相当于在模型运行时使n参数生效
    mdlWks.assignin('n', n);

    % 运行Simulink仿真并获取结果
    % 'ReturnWorkspaceOutputs' 选项确保输出返回到工作区
    Sim_result = sim(mdlName, 'ReturnWorkspaceOutputs', 'on');

    % 从仿真结果中提取最终输出值
    % 假设模型包含名为"sum"的Outport模块
    % .Data 获取数据数组，end 表示取最后一个时间步的数据
    outputDatas = Sim_result.sum.Data(end);

    % 将当前结果追加到结果矩阵
    result = [result; outputDatas];
end

% 最终显示所有迭代结果
result
```
